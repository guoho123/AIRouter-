 **当前版本：v1.0.5** ｜ Android 7.0 及以上

AIRouter 是一个装在安卓手机上的 AI 机器人 App。它把多个 AI 模型、聊天平台和本机功能整合到一起，让你的手机变成一个 24 小时在线的私人 AI 助手。

---

## 1. 这个 App 能做什么

装上 AIRouter 后，你可以：

- **聊天**：在 QQ 或 Telegram 里和 AI 对话，群聊、私聊都支持。
- **多模型**：同时配置多个 AI 模型，一个出问题自动换下一个，不用手动切。
- **有记忆**：告诉它「记住：我喜欢喝美式」，以后它会记得。
- **会发图**：收藏表情包，聊天时它会挑合适的发出来。
- **会说话**：收到语音会自动转成文字；也能用语音回复你。
- **能看图**：发图片给它，它可以识别图片内容。
- **能搜索**：需要最新信息时，可以联网搜索并核对来源。
- **会提醒**：说「提醒我明天下午3点开会」，到点会提醒你。
- **能管文件**：在电脑网页上浏览手机文件、上传下载、在线编辑。
- **可扩展**：插件商店里有离线语音识别、人设、代理、内网穿透等插件。

> 简单理解：**手机负责运行，电脑网页负责设置，QQ / Telegram 负责聊天。**

## 2. 使用前准备

开始前，请准备好下面几样东西：

| 准备项 | 说明 | 是否必须 |
| --- | --- | --- |
| 安卓手机 | Android 7.0 及以上，建议长期插电 | 必须 |
| 同一 Wi-Fi 的电脑 | 用浏览器打开控制台进行设置 | 必须 |
| AI 模型 API | 一个 OpenAI 兼容的接口地址和密钥 | 必须 |
| Telegram 机器人 | BotFather 创建的 Bot Token | 二选一 |
| QQ 官方机器人 | QQ 开放平台的 AppID 和 AppSecret | 二选一 |

补充说明：

- **模型 API** 可以从各家大模型平台或中转站获取。地址必须是可以直接请求的完整对话接口，通常以 `/v1/chat/completions` 结尾。
- **Telegram** 在国内需要能够访问 Telegram 的网络环境。如果连不上，可以安装插件商店里的代理插件。
- **QQ 官方机器人** 需要在 QQ 开放平台创建应用，并具备开发者资质。没有资质的话，建议先用 Telegram 测试。
- 只想当普通群成员使用机器人的人，**不需要安装 App，也不需要配置**，直接在群里 @ 机器人即可。

## 3. 安装 App

1. 下载安装包 `xyAIRouter-release.apk`。
2. 手机上如果提示「禁止安装未知来源应用」，按提示允许当前浏览器或文件管理器安装。
3. 安装完成后打开 AIRouter。
4. 按提示允许**通知权限**，这样 App 才能在后台稳定运行。
5. Android 9 及以下系统，首次使用文件管理时还需要允许**存储权限**。

打开后你会看到：

- 手机屏幕上显示黑底绿字的**终端日志页**，说明程序正在启动；
- 状态栏出现 AIRouter 的常驻通知，说明服务正在运行；
- 页面会保持常亮，这是正常现象。

> 手机端页面只用来查看运行状态。真正的设置页面在电脑浏览器里。

## 4. 第一次配置（三步）

### 4.1 打开电脑控制台

1. 确认手机和电脑连接的是**同一个 Wi-Fi**。
2. 在手机「设置 → WLAN → 当前网络」里查看手机 IP，例如 `192.168.1.23`。
3. 在电脑浏览器地址栏输入：

```
http://192.168.1.23:8665
```

就能看到 AIRouter 控制台。

小提示：

- 手机端页面是 `http://手机IP:8665/terminal`；
- 电脑端直接访问 `http://手机IP:8665` 即可；
- 如果打不开，先看文末「常见问题」第 1 条。

### 4.2 添加 AI 模型

进入左侧「**模型设置**」：

1. 点击「**+ 添加模型**」；
2. 按下表填写：

| 字段 | 怎么填 | 示例 |
| --- | --- | --- |
| ID | 自己起一个不重复的名字 | `m1` |
| 别名 | 方便识别的名字 | `主力模型` |
| API 地址 | 完整的对话接口地址 | `https://api.xxx.com/v1/chat/completions` |
| API Key | 平台提供的密钥 | `sk-...` |
| 模型名 | 平台要求的具体模型名称 | `deepseek-chat` |

3. 保存后，在「**全局默认模型 ID**」里填入刚才的 ID（例如 `m1`），再保存。

建议：

- 可以添加 2 个以上模型作为备用，靠前的优先使用；
- 前一个模型超时或报错，会自动切换到下一个；
- 如果你只填了模型平台的主域名，没有填完整的 `/chat/completions` 地址，会请求失败；
- 纯文字模型不要用来识别图片，效果会不好或直接报错。

### 4.3 添加机器人

进入左侧「**机器人设置**」：

1. 点击「**+ 添加机器人**」；
2. 选择类型并填写：

**Telegram**

| 字段 | 怎么填 |
| --- | --- |
| ID | 自己起名，例如 `tg1` |
| 类型 | Telegram |
| Token / Secret | BotFather 给你的 Bot Token |
| 专属人设 | 可不填，默认使用全局人设 |
| 入群欢迎语 | 可不填 |
| 启用 | 勾选 |

**QQ 官方**

| 字段 | 怎么填 |
| --- | --- |
| ID | 自己起名，例如 `qq1` |
| 类型 | QQ 官方 |
| Token / Secret | 开放平台的 AppSecret |
| AppID | 开放平台的 AppID |
| WS 地址 | 保持默认 `wss://api.sgroup.qq.com/websocket` |
| 入群欢迎语 | 可不填 |
| 启用 | 勾选 |

保存后，机器人状态变成 **online / 在线**，就说明连接成功了。

注意：

- 最多同时启用 3 个机器人，其中 QQ 官方最多 2 个；
- QQ 群聊一般需要 **@ 机器人**才会回复，私聊直接发；
- QQ 官方机器人有主动消息额度，提醒等功能不要设置得太频繁。

### 4.4 测试一下

点击控制台右下角的 `✦`，打开**聊天测试**：

1. 选择一个测试会话；
2. 发送「你好」；
3. 能正常回复，就说明模型和机器人链路都通了；
4. 再去 QQ 或 Telegram 里实际发一条消息确认。

## 5. 日常聊天怎么用

- **QQ 群聊**：@ 机器人后输入内容。
- **QQ 私聊**：直接发送。
- **Telegram**：私聊直接发送；群聊里可以 @ 或按机器人设置响应。
- 支持发**图片、语音、视频、文件**，机器人会按配置识别或处理。
- 连续发几条消息时，机器人会自动合并后再回复，避免把「图片 + 文字」拆开处理。
- 模型偶尔回复慢或失败时，会自动换用下一个可用模型，不需要你操作。
- 如果开启了群管理，刷屏、敏感词、非管理员使用管理指令等行为会被拦截。

> 普通群成员只需要聊天，不需要登录任何后台。

## 6. 常用功能与说法

### 6.1 让它记住事情

直接聊天即可：

| 你可以说 | 效果 |
| --- | --- |
| `记住：我喜欢喝美式` | 写入当前会话的长期记忆 |
| `忘掉：美式` | 删除相关记忆 |
| `查看记忆` | 列出当前会话记住的内容 |
| `忘掉全部记忆` | 清空当前会话记忆 |

记忆按「机器人 + 会话」分开保存，群聊和私聊互不影响。

### 6.2 定时提醒

| 你可以说 | 效果 |
| --- | --- |
| `提醒我 10分钟后 喝水` | 10 分钟后提醒 |
| `提醒我 18:30 下班` | 当天 18:30 提醒 |
| `提醒我 明天下午3点 开会` | 第二天下午 3 点提醒 |
| `提醒列表` | 查看还没到时间的提醒 |
| `取消全部提醒` | 清空当前会话提醒 |

QQ 主动消息有额度限制，提醒不要设置得过于频繁。

### 6.3 换人设

如果你配置了多套人设：

| 指令 | 效果 |
| --- | --- |
| `/人设` | 查看可用人设 |
| `/人设 名称` | 切换到指定人设 |
| `/人设 默认` | 恢复默认人设 |

### 6.4 生成日记

发送：

```
/diary
```

机器人会根据今天的聊天内容生成一篇 Markdown 日记，保存在手机里，也可以在控制台「记忆日记」中查看和修改。

### 6.5 收藏和使用表情包

收藏：

- 给机器人发一张图片，并在消息里写「**保存为开心**」，这张图就会以「开心」为名字收录；
- 也可以在电脑控制台「表情包管理」里直接上传。

使用：

- 聊天时说到合适的气氛，机器人会自动挑图发出来；
- 也可以用 `/emoji` 查看当前图库；
- 图库没有合适的图时，它还可以联网搜索表情并自动收藏。

### 6.6 联网搜索与核对

- 需要最新信息时，机器人会自动联网搜索；
- 支持多个搜索来源交叉核对，并标注信息可信度和来源是否一致；
- 你也可以直接发 `/search 今天的新闻` 主动搜索。

### 6.7 点歌

```
/点歌 晴天 周杰伦
```

机器人会返回可播放的音乐链接。

### 6.8 查询手机状态

```
/status
```

可以查看 CPU、内存、磁盘、运行时长和当前使用的模型。

### 6.9 语音、图片和视频

- **发语音**：机器人会自动转成文字再理解；安装离线语音插件后，断网也能识别。
- **发图片**：开启多模态后，它能看懂图片内容。
- **发视频**：会抽取几个关键画面来理解视频内容。
- **收语音**：机器人可以用语音回复你。
- **收视频**：在模型支持的情况下，也可以发送视频。

### 6.10 文件收发

管理员可以把文件放到手机上的分享目录，然后让机器人发送：

```
/sendfile
```

不带参数会列出可发送的文件；也可以写文件名或序号。

收到的文件会保存在「文件管理 → 收件箱」里。

## 8. 插件商店

进入「**插件商店**」，刷新后可以看到作者维护的插件。点击安装即可，装好后在「插件管理」里启用或停用。

目前可用的插件：

| 插件 | 作用 | 使用建议 |
| --- | --- | --- |
| 本地离线语音识别 | 不联网也能把语音转成文字 | 装好后先下载约 42MB 的模型 |
| 鲸鱼娘毒舌人设 | 增加一套毒舌短句人设 | 用 `/xyai` 切换 |
| VLESS-WS 出站通道 | 让手机上的请求走代理 | 懂网络配置再用 |
| ChmlFrp 内网穿透 | 把手机端口映射到公网 | 有远程访问需求再用，注意安全 |

说明：

- 插件包不大，安装很快；插件商店服务由作者维护；
- 离线语音识别第一次使用会慢一些，第二次通常会快很多；
- 卸载「本地离线语音识别」不会删除已下载的 42MB 模型，重装后不用重新下载；需要释放空间时，可在插件里点「删除模型」；
- 代理和内网穿透插件涉及网络配置，不熟悉的话建议保持默认、先不安装。

## 9. 文件管理

电脑控制台里的「**文件管理**」可以：

- 浏览 App 内部目录、App 外部目录和手机存储；
- 预览图片、播放音频和视频；
- 在线编辑文本文件并保存；
- 上传、下载、新建文件夹、重命名、删除；
- 解压 zip 压缩包；
- 查看机器人收到的文件（收件箱）。

限制：

- 单个上传文件不超过 200MB；
- 在线编辑只支持文本，单文件不超过 2MB；
- 解压后的总大小不超过 1GB；
- Android 11 及以上系统对手机存储有访问限制，部分目录可能看不到，这是系统限制。

「**AI 编辑**」开关打开后，管理员可以让 AI 读取、修改、重命名、删除和恢复文件。为了避免误操作，建议平时保持关闭，需要时再开。

## 10. 更新、备份与换手机

### 更新

进入「关于开发者 → 检查更新」，如果有新版本，会显示更新说明和下载地址。

直接下载新 APK **覆盖安装**即可，配置和数据都会保留。

### 备份

建议定期备份：

1. 打开「文件管理」；
2. 进入 App 内部目录；
3. 下载 `config.json`、`memory.json` 和 `ai` 文件夹。

这些文件里包含模型密钥、机器人配置、记忆、日记和表情包，请妥善保管，不要发给别人。

### 换手机

1. 在旧手机上按上面的方法备份；
2. 在新手机安装同版本或更新版本的 APK；
3. 用新手机打开一次控制台；
4. 通过「文件管理」把备份文件上传回对应目录；
5. 重启 App，检查模型和机器人是否正常。

> 卸载 App 会清除全部本地数据；覆盖安装不会。卸载前一定要先备份。

## 11. 常见问题

**1. 电脑打不开控制台？**

- 确认手机和电脑在同一个 Wi-Fi；
- 确认手机 IP 没有填错；
- 路由器如果开了「AP 隔离」，设备之间不能互访，需要关闭；
- 确认 App 的通知还在，服务没有被系统杀掉；
- 会用数据线的话，可以在电脑执行 `adb forward tcp:8665 tcp:8665`，然后访问 `http://127.0.0.1:8665`。

**2. 手机页面只有黑底绿字，没有设置界面？**

正常。手机页面只显示运行日志，设置请用电脑浏览器打开控制台。

**3. 机器人在线但不回复？**

- QQ 群聊需要 @ 机器人；
- 检查「机器人设置」里是否勾选启用；
- 检查是否命中限流、敏感词或被屏蔽；
- 检查「指令管理」里该指令是否仅管理员可用；
- 打开「日志查询」看具体错误。

**4. 模型报错 401 / 404 / 400？**

- `401`：API Key 错误、过期或没有余额；
- `404`：API 地址不完整，通常要填到 `/v1/chat/completions`；
- `400`：模型名不对，或内容超出模型限制。

**5. Telegram 一直连不上？**

手机需要能访问 Telegram。可以换网络，或安装插件商店里的代理插件。

**6. QQ 机器人发不出消息？**

- 确认机器人已邀请进群；
- 确认开放平台里的权限和回调配置正确；
- 主动消息有额度，提醒太频繁会被限制；
- 查看日志里的平台返回信息。

**7. 语音识别失败或很慢？**

- 先安装「本地离线语音识别」插件，并下载模型；
- 模型没下完时，识别会失败；
- 老机型第一次识别会慢一些，之后会好很多；
- 也可以配置云端语音识别作为兜底。

**8. App 老是被系统杀掉？**

- 允许通知权限，保持常驻通知；
- 在系统设置里关闭对 AIRouter 的电池优化；
- 不要从最近任务里手动划掉 App；
- 长期使用建议插着充电器。

**9. 文件管理看不到手机里的照片？**

Android 11 及以上系统限制了全盘访问，部分目录看不到属于正常现象。可以继续使用 App 内部和 App 外部目录。

**10. 插件安装失败？**

- 检查网络是否能打开插件商店；
- 刷新后重试；
- 插件包超过 8MB 或校验失败时会拒绝安装；
- 打开日志查看具体原因。

**11. 用这个 App 要另外付费吗？**

App 本身不收取模型费用。你调用 AI 模型产生的费用由对应的模型平台按量计费，价格以平台为准。

**12. 聊天记录会被上传吗？**

聊天记录、记忆、日记、表情包都保存在手机本地，作者的服务端只提供插件商店、公告和版本信息，不接收聊天内容。

**13. 更新会丢数据吗？**

覆盖安装不会。卸载会清除全部数据，请先备份。

**14. 苹果手机能用吗？**

目前只支持安卓。

## 12. 使用须知

- **控制台没有密码**：默认只在局域网内访问。请不要把 `8665` 端口直接暴露到公网，也不要在公共 Wi-Fi 下使用。
- **保管好密钥**：模型 API Key 和机器人密钥保存在手机本地配置里，备份文件不要随意外传。
- **注意费用**：模型调用按平台计费，请留意余额和用量。
- **遵守平台规则**：QQ 官方机器人需要开发者资质，主动消息有额度；Telegram 需要可访问的网络环境。
- **内容责任**：AI 生成的内容不一定正确，请自行判断后再使用。
- **设备状态**：长期运行会占用少量 CPU 和电量，老手机可能发热，建议插电并放在通风处。
- **卸载清空**：卸载 App 会删除配置、记忆、日记、表情包和文件，卸载前请备份。
