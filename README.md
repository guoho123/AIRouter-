# AIRouter 正式发布：把一台旧安卓手机，变成你的私有 AI 路由中枢

**AIRouter（AI 路由中枢）v1.0 正式发布。**

它是一套跑在安卓手机本地的 AI 网关：统一管理多家大模型，请求失败自动切换；接入 Telegram 与 QQ 官方机器人；自带长期记忆、表情包图库、自然语言提醒、联网搜索与插件商店。所有聊天数据留在手机本地，不需要额外购买服务器。

### 为什么做 AIRouter

过去一年，能用的模型越来越多，但真正用起来并不轻松：

- 模型散落在不同平台，Key 要分开记，换一个模型就得改一次代码；
- 想让 AI 常驻聊天软件，通常要先有一台云服务器，再处理备案、域名、保活；
- 旧手机躺在抽屉里，性能和网络其实足够跑一个轻量网关。

AIRouter 的出发点很简单：**把「多模型路由」和「聊天机器人」收进一台手机，做成一个可以长期挂着跑的本地服务。**

### AIRouter 是什么

打开 App，手机会在本地启动一个 Python 网关（`127.0.0.1:8665`），由前台服务负责保活。手机屏幕显示终端日志页；同一 Wi-Fi 下，电脑浏览器访问 `http://手机IP:8665` 就能打开完整控制台。

它不训练模型，也不代理贩卖算力。它做的是路由与编排：把你已有的模型 API、聊天平台和本地数据组织成一套可持续运行的机器人系统。

### 核心能力

**1. 多模型统一路由，失败自动切换**

在控制台里添加任意 OpenAI 兼容接口（API 地址、Key、模型名）。当主模型超时、断网、鉴权失败或返回异常时，系统会按列表顺序自动切换到下一个可用模型，并在日志中记录切换原因。模型不可用不再等于机器人掉线。

**2. 双平台机器人，完整消息闭环**

支持 Telegram（长轮询）与 QQ 官方机器人（WebSocket）。每条消息依次经过：去除 @、记忆指令拦截、内置指令、插件指令、自定义指令、AI 回复、记忆落盘。断线自动重连，实例启停由网页控制。

为避免资源失控，默认限制同时启用 3 个机器人，其中 QQ 官方最多 2 个。

**3. 双轨记忆与每日日记**

- 短期上下文：保留最近几轮对话，控制 Token 消耗；
- 长期记忆：通过「记住：xxx」「忘掉：xxx」维护，每轮对话自动注入人设；
- 记忆日记：`/diary` 读取近期上下文，生成当天 Markdown 日记，可在控制台查看和编辑。

**4. 群管理守卫**

刷屏限流、管理员名单、敏感词拒答、屏蔽指定会话、指令仅管理员可用。被限流的消息会静默丢弃，不消耗 Token。

**5. 表情包图库**

聊天中直接发图即可收录；AI 在合适的气氛下会自动插入 `<emoji>名称</emoji>` 发图。图库没有合适图片时，可用 `<emoji_search>关键词</emoji_search>` 联网搜图并自动入库。

**6. 自然语言提醒**

在聊天里说「提醒我 明天下午3点 开会」，系统会解析时间并在到点时主动推送。支持「10分钟后」「18:30」「明天下午3点」「后天早上8点」等写法。

**7. 联网搜索、点歌与识图**

模型可自主调用 `<search>` 联网搜索实时信息；`/点歌 晴天 周杰伦` 返回可点开的歌曲链接；开启多模态后，QQ / TG 收到的图片可直接交给支持视觉的模型识别（最多 3 张）。

**8. 插件系统与插件商店**

插件通过装饰器注册指令与钩子，支持热开关。除内置插件外，还能从插件商店安装外部插件：服务端用一条 `php publish.php src/插件目录` 完成打包、归档与清单重建，支持 Python 插件和表情包两种包型。

**9. 网页控制台**

仪表盘、日志查询、机器人设置、插件管理、插件商店、指令管理、记忆日记、表情包管理、提醒管理、模型设置、关于开发者，共 11 个页面。CPU、内存、Token 消耗、运行时长一目了然。

**10. 远程运营能力**

服务端可发布公告、维护版本信息，客户端「检查更新」会比对版本号并展示更新说明。运营与聊天数据彻底分离，服务端不接触任何对话内容。

### 技术架构

```
安卓 App（Kotlin）
├─ 前台常驻服务：保活 + 启动 Python + CPU 上报
├─ WebView：加载本机终端页
└─ Chaquopy：内嵌 Python 3.8 运行时
        │
        ▼
本地网关 127.0.0.1:8665（Python）
├─ 模型路由：多模型配置 / 自动容错 / Token 统计
├─ 机器人引擎：Telegram 长轮询 / QQ 官方 WebSocket
├─ 本地数据：config.json、记忆、日记、表情包、提醒
├─ 插件系统：内置插件 + 商店插件动态加载
└─ 网页控制台 + JSON API
        │
        ├──▶ 各模型 API（OpenAI 兼容）
        ├──▶ Telegram / QQ 开放平台
        └──▶ 插件商店与公告服务（PHP，可选自建）
```

App 支持 Android 7.0 及以上，同时打包 32 位（armeabi-v7a）与 64 位（arm64-v8a），老机型也能安装。

### 适合谁

- 手里有闲置安卓手机，想低成本长期挂一个 AI 机器人；
- 同时使用多个模型，希望统一入口并具备故障切换；
- 需要自己掌握聊天记录与记忆数据，不希望上传到第三方后台；
- 愿意自己准备模型 API 与机器人账号的开发者或重度用户。

### 不适合谁

- 期待开箱即用、无需任何配置的用户；
- 需要高并发、多租户、SLA 保障的生产业务；
- 无法接受手机长期插电运行的用户。

### 三步开始使用

1. **安装**：安装 AIRouter APK，打开后允许通知权限，保持前台服务运行；
2. **配置模型**：电脑浏览器打开 `http://手机IP:8665`，进入「模型设置」，填写 API 地址、Key、模型名，并设置默认模型；
3. **接入机器人**：进入「机器人设置」，添加 Telegram Bot Token 或 QQ 官方 AppID / AppSecret，保存并启用。

配置完成后，在「聊天测试」窗口先发一条消息验证链路，再让机器人在群里工作。

### 边界与注意事项

- **模型费用**：AIRouter 不提供模型额度，所有调用费用由你所配置的 API 账户承担；
- **平台资质**：QQ 官方机器人需要相应的开发者资质，主动消息存在额度限制；Telegram 需要可访问的网络环境；
- **数据位置**：配置、记忆、日记、表情包均保存在 App 私有目录，卸载即清除，请自行备份；
- **控制台安全**：控制台默认监听局域网地址且没有登录鉴权，请只在可信网络中开启，不要在公共 Wi-Fi 下暴露端口；
- **运行成本**：前台服务会持续占用少量 CPU 与电量，建议插电使用，并留意老机型的发热情况；
- **内容责任**：机器人输出由模型生成，请遵守所在平台规则与当地法律法规，并对实际发布的内容负责。
